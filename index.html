关于手册

站点定位、内容组织方式与常见问题，以手册条目形式呈现。

LUNLI(1)  ·  论理电影网 Manual  ·  lunlidianyingwang-cn.github.io

NAME
论理电影网 —— 电影推荐与影视资讯索引站点
SYNOPSIS
提供精选片单、热门榜单、分类目录与资讯日志四大板块内容，覆盖伦理剧情、家庭、社会现实等类型。
DESCRIPTION
论理电影网致力于用清晰的分类与实时榜单降低找片成本，让每一次观影都更值得。内容按「类型 · 地区 · 年代」三维组织。
RANKING
热榜如何排序？榜单依据站内浏览热度、用户评分与互动数据加权计算，每日 08:00 刷新一次，并在榜单页同步展示热度条与评分。
MOBILE
手机端体验如何保证？页面采用响应式布局，小屏下文件列表隐藏权限与体积列、热度条收起、目录树与手册转为单列，保证阅读与点击顺畅。
CONTACT
如何联系本站？可通过页脚「关于与联系」栏目提交合作、投稿或版权相关反馈，我们会在收到后尽快处理。
